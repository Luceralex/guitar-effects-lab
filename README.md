# Mentor

一个开源的吉他效果器和弹奏助手，在浏览器里就能用。

我们最初只是想接上电吉他，在电脑上调调音色。练琴时又常遇到另一个问题：听着觉得不对，却不知道是弹错了音、音没按准，还是节奏没跟上。Mentor 就是沿着这两个需求慢慢做出来的。

现在你可以用它调音色、看自己弹的是什么音，也可以载入曲谱，边弹边看反馈。乐谱会跟着弹奏往前走，方便把注意力留在琴上。

**[在线试玩 →](https://luceralex.github.io/guitar-effects-lab/)** · [下载源码](https://github.com/Luceralex/guitar-effects-lab/archive/refs/heads/main.zip) · [详细使用说明](docs/guide.md)

## 可以用它做什么

### 调音色

过载、均衡、压缩、降噪门、自动哇、合唱、镶边、移相、颤音、延迟和混响都可以单独开关、调整。可以先选一个音色组合，再按自己的听感微调，用 A/B 对比处理前后的声音。设置会保存在当前浏览器里。

### 跟着曲谱练

支持导入 MusicXML 五线谱，或粘贴文本六线谱。页面同时显示五线谱和六线谱，并提示当前音符对应的指板位置。

- **自由跟弹**：按自己的速度弹，命中当前音后，乐谱继续向前。
- **节拍跟弹**：设置 BPM，跟着节拍练，查看早弹、晚弹、漏弹和时值偏差。
- **先听一遍**：用内置音源试听谱子，再开始练习。

### 看清自己弹的音

显示检测到的音名和音分偏差，帮助检查音准。选好根音与音阶后，指板会标出调内音；也可以按提示逐音练习音阶。

### 看声音发生了什么变化

频谱、波形和频谱图可以对比效果器处理前后的声音。想知道过载加了哪些谐波，或者 EQ 改了哪段频率，可以在「音频分析」里看。运行本地版后，还能对音频文件做全曲频谱和基频等深度分析。

## 先试一下

打开[在线试玩](https://luceralex.github.io/guitar-effects-lab/)，不需要安装，也不需要账号。

- **手边没有吉他**：展开「内置乐器与试听键盘」，试听音色；点击「载入乐谱」，选一个示例。
- **想用已有录音**：把声音来源切到「音频文件」，载入自己的录音。
- **想接电吉他**：把带吉他输入的音频接口连到电脑，点击「连接吉他」，允许浏览器使用音频输入，再选择输入和输出设备。先调低监听音量。

请用桌面版 Chrome 或 Edge 体验。实时音色处理、音高检测和曲谱跟弹都在浏览器本机运行，演奏音频不会上传到 GitHub。在线版由 GitHub Pages 提供静态网页；深度分析需要本地 Python 服务。

## 下载到电脑上用

本地版包含在线版的功能，以及音频文件的深度分析。需要 Python 3.10 或更新版本。

1. [下载源码](https://github.com/Luceralex/guitar-effects-lab/archive/refs/heads/main.zip)并解压。
2. 在项目文件夹里打开终端，安装依赖：

   ```powershell
   python -m pip install -r requirements.txt
   ```

3. Windows 用户双击 `启动 Mentor.bat`。其他系统在终端运行：

   ```bash
   python server.py
   ```

4. 浏览器打开 `http://127.0.0.1:8765/`。

启动失败时，可以运行 `python server.py` 查看错误，或检查项目里的 `guitarlab.log`。

## 目前还有哪些限制

Mentor 还在完善中，下面几件事会影响实际体验：

- **监听延迟取决于设备、系统和浏览器。** 有些接法会出现明显延迟；页面里的输入补偿只调整评分时间，不能消除听到的延迟。音箱如果同时开着硬件直通，也可能听到两路声音。[接线与排查](docs/guide.md#guitar-input)
- **音高判断对干净的单音更可靠。** 和弦检测有局限，单路音频也不能确定你实际按了哪根弦、哪一品。
- **节奏练习优先用 MusicXML。** 文本六线谱缺少准确时值，程序只能按列距估计。MusicXML 目前读取第一个乐器声部，复杂谱面的排版还不完整；扫描图片暂不支持识别。

## 开发与反馈

前端是 HTML、CSS 和 JavaScript，使用 Web Audio API 处理实时声音、Canvas 绘制谱面与音频图像；本地服务使用 Python / FastAPI。静态网页无需构建。

[使用与开发说明](docs/guide.md)里有代码结构、信号链和格式支持的详细信息。运行自动化测试：

```bash
npm ci
npm test
```

遇到问题，欢迎[提 Issue](https://github.com/Luceralex/guitar-effects-lab/issues)。涉及声音或跟弹时，请顺手写上系统、浏览器、输入输出设备，以及复现步骤；乐谱问题可以附一段能复现的谱子。也欢迎提交改进。
