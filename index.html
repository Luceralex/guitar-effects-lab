展开声音与效果器原理资料

为什么小提琴和钢琴拉同一个 440Hz，音色完全不同？

音高由基频决定（440Hz = A4，决定你听到的是哪个音），音色由泛音（谐波）结构决定。 440Hz 只是频谱上最左边那根峰（基频 f0），小提琴和钢琴在 880、1320、1760…（第 2、3、4 次谐波）处的峰完全不同：

  • 小提琴：弓子持续拉动，谐波按约 1/k 递减且稳定持续，还有 5~6Hz 的揉弦（频率微微波动）和弓擦弦的噪声。
  • 钢琴：琴锤敲击，起音瞬间高次谐波很亮，随后整体指数衰减、高次谐波衰减更快；琴弦刚度还让第 k 次谐波比 k·f0 略偏高（非谐性），所以更"金属"。
  • 正弦波：只有一根峰 —— 没有泛音，所以"没有音色"。

从时域看：两个信号每 1/440 秒重复一次（周期相同 → 音高相同），但一个周期内的波形形状不同。 傅里叶级数告诉我们：波形形状 = 各次谐波幅度与相位的叠加。波形不同 ⇔ 泛音结构不同 ⇔ 音色不同。

验证方法

  1. 选"小提琴"，按住 A4，看频谱：等间距排列的峰 440 / 880 / 1320…（f0、H2、H3…标记）。
  2. 切到"钢琴"再按 A4：峰的高度分布不同；切到"频谱图"，衰减过程的差别一目了然。
  3. 点"小提琴 vs 钢琴"，峰值保持线会替你把两次的频谱叠在一起对比。

各效果器在频谱上做了什么？

  • Drive（增益·过载）：把波形放大到削顶 → 波形趋近方波 → 频谱冒出大量新谐波峰。 选正弦波（失真≈0，频谱只有一根峰），打开 Drive，看失真读数飙升、频谱长出一排峰 —— 这就是失真音色的数学本质。
  • EQ（均衡）：直接搬动频谱形状。三段增益 ±15dB，蓝色虚线就是 EQ 的频响曲线，叠加显示在频谱上。
  • Chorus（合唱）：信号复制两份，各经过被慢速 LFO 调制的 ~20ms 延时 → 副本频率微微上下漂移，与原信号产生拍频 → 听感变"厚"。 频谱上单峰被抹宽，这就是厚度的来源。
  • Delay（延迟）：原信号 + 延迟副本，副本再反馈回去形成回声序列。切到频谱图看平行的回声条纹；切到波形看一串重复脉冲。
  • Compressor（压缩）：超过阈值的部分按比率压下来 → 动态变小、听感更密。看卡片上的 GR 表：信号越响，压得越多。

建议的实验路线

  1. 正弦波 + A4 → 记住"纯音"的样子（1 根峰，失真≈0）。
  2. 开 Drive → 频谱长出谐波 → 理解"削波 = 新增泛音 = 失真"。
  3. 小提琴 A4 + EQ 高频 +12dB → 高次谐波被抬高 → 音色变亮。
  4. Delay 300ms / 反馈 50% → 频谱图看回声条纹；把反馈拉满听自激。
  5. Chorus 深度拉满 → 频谱峰变宽；对比开/关用"A/B"。
  6. 加载你自己的音乐文件，用 EQ 抠"人声频段"（约 300Hz–3kHz）感受频率与听感对应关系。
